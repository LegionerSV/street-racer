# Street Racer

Локальная браузерная гонка по реальным улицам. Стартовый район — 2 × 2 км, дальше карта подгружается по ходу движения. Проект: `D:\Сережа\Projects\street-racer`.

## Запуск

1. Запустите `start-game.cmd` двойным щелчком.
2. Откройте `http://localhost:3000` в Chrome или Edge с включённым аппаратным ускорением.
3. Выберите центр района на карте или введите координаты и нажмите кнопку со стрелкой. Нажмите «Выехать на улицы».

Окно запуска должно оставаться открытым. Для остановки нажмите Ctrl+C. Требуется Node.js 22.13 или новее; при первом запуске зависимости устанавливаются автоматически, если их ещё нет.

После выключения компьютера достаточно снова запустить `start-game.cmd`: повторная сборка не нужна. Если готовой сборки нет, файл запуска создаст её автоматически. После изменения исходников выполните `npm run build`; для разработки с автоматическим обновлением — `npm run dev -- --host 127.0.0.1 --port 3000`.

Первое получение нового района зависит от публичного Overpass API и может занимать несколько минут. Данные высот и завершённые клетки карты сохраняются в IndexedDB браузера. Повторный запуск того же участка использует кэш. Не удаляйте данные сайта, если хотите сохранить районы и рекорды. Карта выбора загружается из сети; сохранённые геоданные для игры доступны без повторного скачивания. Дальние клетки выгружаются из оперативной памяти: фиксированная игровая граница 5 × 5 км снята, а объём данных ограничен скользящим окном и бюджетом объектов. Подробности, ограничения и диагностика: [Подгрузка карты](docs/map-streaming.md).

## Управление

| Клавиши | Действие |
| --- | --- |
| WASD / стрелки | Газ, тормоз, задний ход, поворот |
| Пробел | Ручник и занос |
| Shift | Нитро с автоматическим газом |
| R | Восстановить машину на дороге |
| E | Начать гонку у маркера / закрыть результат |
| Esc | Пауза и настройки |

Зелёные маркеры обозначают спринт и кольцевой заезд. В кольце три круга, в каждом заезде три соперника. Маршруты строятся по доступной дорожной сети: в районе без подходящего кольца такой маркер отсутствует. Обычный трафик останавливается на красный, соперники в гонке могут нарушать сигналы.

## Версия 06 / LOCAL

Добавлены сенсорные кнопки с одновременным удержанием газа, руля, ручника и нитро. Отпускание, отмена жеста, потеря фокуса, пауза и ошибка загрузки сбрасывают управление. Сенсорные кнопки можно включить вручную в паузе.

Нитро включается Shift или экранной кнопкой и само добавляет газ. Полного заряда хватает примерно на 4,5 секунды; восстановление занимает 18 секунд активного игрового времени. На тормозе, ручнике и в воздухе заряд не расходуется, а в паузе и отсчёте заморожен.

Профиль «Для телефона» выбирается автоматически при первом запуске с сенсорного устройства. Уменьшены дальность деталей и трафика, разрешение, кэш кварталов, слой мини-карты и эффекты дождя; отключены тени и постобработка. Полный район и маршруты сохранены. Предельный поток в этом профиле — 20 / 36 / 48 машин возле игрока.

Запуск на телефоне — через `start-mobile.cmd` и одну Wi-Fi сеть с компьютером. Отдельная статическая сборка `npm run build:pages` сохраняется в `out` и подходит для GitHub Pages. Подробности: [Телефон и GitHub Pages](ТЕЛЕФОН-И-PAGES.md). Сайт пока не опубликован.

## Версия 05 / LOCAL

Исправлен слишком слабый поворот после 60 км/ч: ослаблено ограничение кривизны и учтена упругость шин. Руль охотнее меняет траекторию, сохраняя отдельный режим ручника и стабилизацию. В физическом контрольном повороте на 80 км/ч за 1,5 с направление меняется на 36° вместо 21°. Новые тесты проверяют повороты в обе стороны на 60–120 км/ч и устойчивость в затяжной дуге; полный набор — 82 теста.

После обновления запустите start-game.cmd снова и обновите страницу Ctrl+F5. Удалять сохранённый район не нужно. Подробности и ограничения визуальной проверки — в `ПРОВЕРКА.md`.

## Версия 04 / LOCAL

Обычный поворот ограничен доступным сцеплением, с плавным рулём и стабилизацией. Ручник отдельно разрешает занос; исправлен знак стабилизации при заднем ходе. Камера ниже и ближе, без передачи наклона кузова на горизонт; поле зрения плавно расширяется с ростом скорости.

Полосы OSM теперь сохраняются по направлениям: количество, смещения траекторий и разделительная линия используют одни данные. Учтены обратное одностороннее движение, явный oneway=no, общие полосы и встречные выделенные полосы на односторонней дороге. Под названием улицы видно число полос; знак ≈ означает оценку при отсутствии данных. Геометрия разметки имеет штрихи длиной 3 м через 6 м промежутка, независимо от узлов OSM и кварталов. Точная организация поворотов из каждой полосы пока не воспроизводится: соответствующие теги сохранены, но не используются как полноценные правила перестроения.

Трафик получил седаны, хэтчбеки, кроссоверы и фургоны с разными кузовами и размерами. Спортивная машина отличается низким силуэтом, полосами и антикрылом; соперники также используют спортивные кузова. Повторяющиеся модели разделяют геометрию и материалы.

Проверочный участок: Пушкин, Госпитальный переулок, центр 59.7057 / 30.3805. Длина OSM way 31377447 по геодезической формуле — около 946 м; две полосы, ширина в источнике отсутствует и оценивается в 6,8 м. Полный переулок при постоянных 60 км/ч занимает около 57 секунд, при 100 км/ч — около 34 секунд, без учёта разгона и торможения. Глобальное сжатие карты не применяется. Скорость на приборе берётся из фактической горизонтальной скорости физического тела. Поле simulationRate в отладке показывает отношение игрового времени к активному времени работы, чтобы отличать масштаб от замедления на слабой частоте кадров.

73 теста проходят, включая обычный поворот под газом, задний ход, мокрый тормозной путь, все три соперника, размеры разных кузовов и 100 м за 10 с при 36 км/ч с кадровой частотой 30/60/120. Это проверка симуляции, не измерение FPS видеокарты. Визуальная приёмка версии 04 остаётся незавершённой из-за сбоя запуска инструмента браузера; детали в `ПРОВЕРКА.md`.

## Версия 03 / LOCAL

Переработаны подвеска, ручник, инерция и столкновения. У трафика появились плавные траектории, стоп-сигналы и поворотники; у соперников — спортивный разгон и перестроения. Добавлены наклонные обочины, исправления опор, окон и надземных проездов. Мини-карта имеет линейку 200 м, справа отображается пройденное расстояние.

В паузе доступны погода и начало суточного цикла. Сутки проходят за 20 минут игрового времени; во время паузы цикл остановлен. Дождь снижает сцепление и меняет отражения дороги. Значение «Меняется» включает автоматический переход ясной погоды, облачности и дождя.

Текущие результаты и ограничения проверки записаны в `ПРОВЕРКА.md`. Внешний вид новой версии и FPS ещё требуют проверки в браузере: инструмент автоматизации интерфейса сейчас не запускается. Старые замеры производительности к этой версии не относятся.

## Исправления после первого игрового прогона

В версии с отметкой «02 / LOCAL» исправлены наложение земли на асфальт, старт соперников на коротких отрезках OSM и береговой контур воды. Рельеф сглаживается перед построением дорог; дно реки опускается под воду. Название ближайшей дороги отображается в игре, вода и здания — на мини-карте.

В паузе есть плотность трафика: «Свободно» (до 72 машин), «Город» (до 144), «Час пик» (до 220). Это машины возле игрока; фактическое количество зависит от доступных дорог. На многополосных дорогах машины распределяются по полосам. Для нового количества автомобилей производительность в браузере пока не измерена.

После обновления проекта перезапустите файл запуска и обновите страницу Ctrl+F5. Геоданные в кэше удалять не нужно: геометрия строится заново.

## Что воспроизводится

Планировка дорог, расположение и контуры зданий, доступные высоты, вода, парки и светофоры — из открытых источников. Фасады и неизвестная этажность генерируются. Мосты и тоннели получают приблизительные высотные профили с переходами; это не инженерная модель города. Реальные текущие пробки и настоящие циклы светофоров не используются.

Сеть загруженной территории хранится для маршрутов; во время гонки её обновление приостановлено. Геометрия подготавливается в Web Worker по кварталам 250 × 250 м. Вблизи машины включены подробности и коллизии; вдали — упрощённые объекты. Если нужная часть карты или физический квартал ещё не готовы, движение приостанавливается до окончания подготовки. Радиусы уменьшаются настройкой качества.

## Проверки и разработка

```text
npm test
npm run typecheck
npm run lint
npm run build
npm run build:pages
ast-index rebuild
```

Vitest проверяет координаты, дорожные ограничения, маршруты, высотные стыки, светофоры, контрольные точки, хранение и отмену загрузки. Физический тест использует настоящий Havok: подвеска, разгон и торможение. Сценарии написаны в Arrange–Act–Assert.

Также проверяются полный проезд моста и тоннеля, просвет между уровнями, ограничения поворота через промежуточные дороги и финиш всех трёх ботов. Проверка lint охватывает исходники игры и конфигурацию сборки; готовые компоненты шаблона в `components/ui` проверяются TypeScript при общей проверке типов.

Для ручной проверки откройте `http://localhost:3000/?debug`. После загрузки района появятся диагностические кнопки автопроезда, перехода к мосту и тоннелю и показатели сцены. Автопроезд — испытательный контроллер; его застревание не означает успешное прохождение маршрута. Оценивайте результат по фактическому расстоянию, положению и контакту с дорогой. Отладочная панель отсутствует в обычном режиме.

Модули `game/data.ts`, `network.ts`, `chunks.ts`, `world.worker.ts` отвечают за данные и генерацию. `vehicle.ts`, `traffic.ts`, `simulation.ts`, `runtime.ts` — за физику, движение и гонки. React-интерфейс находится в `app/page.tsx`.
