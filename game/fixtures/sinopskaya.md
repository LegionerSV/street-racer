Исходные OSM и DEM для регрессии Синопской набережной, район координат
59.93585, 30.39396. Извлечены из локальных source-тайлов Санкт-Петербурга
13 сентября 2026 года; OSM © OpenStreetMap contributors (ODbL),
высоты — Terrarium из исходных тайлов проекта.

`sinopskaya.json.br` — JSON, сжатый Brotli: три исходных way, их узлы,
полные исходные сетки DEM нужных тайлов, центр и высотный datum отчёта.
Полные сетки нужны для воспроизведения фильтра у границ, без искусственного
обрезания окна. Регрессионный тест не использует сеть.

Воспроизведение из локального набора `work/map-full/saint-petersburg`:
установить `WORLD_PROFILE=fixture` и `WORLD_FIXTURE=1`, затем выполнить
`npx vitest run scripts/world-build-profile.test.ts`.
