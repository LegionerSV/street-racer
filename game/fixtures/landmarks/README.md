# Реальные процедурные достопримечательности

Данные © участники OpenStreetMap, ODbL 1.0. Источник — локальные поставки
`work/map-pilots/moscow` и `work/map-pilots/saint-petersburg`, снимок 2026-09-11.
Полная инвентаризация всех 207 записей двух манифестов предшествует отбору сценариев.

`node scripts/inventory-landmarks.mjs` создаёт полный локальный инвентарь;
`node scripts/landmark-fixtures.mjs` извлекает эти JSON без сетевых запросов.
Сценарии содержат исходные теги, геометрию и рекурсивные зависимости, по одному
примеру каждого значения формы/цвета/материала/угла/направления и отдельные
ансамбли Москвы и Петербурга. Для ансамблей дополнительно включены части
в bounding box и настоящие окружающие улицы. Такой отбор является поиском
кандидатов, а не утверждением, что все они принадлежат одному зданию.

Идентификаторы type/id не заменены синтетическими. Одноимённые Казанские соборы
двух городов и две Ростральные колонны остаются разными объектами.
Недостающие части из исходных PBF в fixture **не добавляются**.

Рендер, связь с оболочкой, OSM-зависимости и бюджет проверяются в
`game/procedural-landmarks.test.ts` и `scripts/landmark-budget.local.test.ts`.
Подробности и ограничения — в `docs/landmark-procedural-report.md`.
