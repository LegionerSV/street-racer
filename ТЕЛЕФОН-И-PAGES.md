# Телефон и GitHub Pages

## Игра на телефоне через домашнюю сеть

1. Подключите компьютер и телефон к одной Wi-Fi сети.
2. На компьютере запустите `start-mobile.cmd`.
3. Откройте на телефоне адрес из строки **Network**, включая окончание `/street-racer/`. Например, `http://192.168.1.10:3001/street-racer/`: цифры адреса будут вашими.
4. Выберите район и дождитесь подготовки. Поверните телефон горизонтально: так дорога лучше видна между кнопками.

Компьютер должен работать, а окно запуска — оставаться открытым. На самом телефоне адрес localhost указывает на телефон, поэтому нужен адрес компьютера из Network. Если Windows спросит о доступе к сети, для домашнего подключения используется частная сеть. При отсутствии соединения проверьте, что телефон не в гостевой Wi-Fi сети.

Сенсорные кнопки появляются автоматически на устройстве с сенсорным основным вводом. В паузе можно включить их вручную: «Сенсорные кнопки» → «Включены». Доступны газ, тормоз/задний ход, повороты, ручник, нитро и возврат на дорогу. Можно удерживать несколько кнопок одновременно. Нитро само добавляет газ: для поворота с ускорением достаточно двух пальцев.

Профиль «Для телефона» выбирается при первом запуске с сенсорного устройства. Если качество уже выбирали вручную, сохраняется ваш выбор. Профиль уменьшает дальность деталей, разрешение, объём кэша и мини-карты, выключает тени и постобработку, сокращает дождь и поток. Район остаётся 5 × 5 км. Трафик поблизости: до 20 / 36 / 48 машин для «Свободно» / «Город» / «Час пик», плюс три соперника. Частота кадров на физическом телефоне пока не измерена.

После изменения исходников обновите сборку командой `npm run build:pages`. После выключения компьютера пересборка не нужна.

## Нитро

На компьютере удерживайте **Shift**, на телефоне — **НИТРО**. Полный заряд даёт около 4,5 секунды ускорения; пустой баллон восстанавливается за 18 секунд активного игрового времени. Заряд отображается возле скорости и на сенсорной кнопке.

Тормоз, ручник, задний ход и отсутствие контакта с дорогой отключают ускорение и расход. Пауза и предстартовый отсчёт останавливают таймер заряда. После исчерпания отпустите кнопку перед следующим включением. Восстановление машины на дороге не выдаёт новый баллон.

## Размещение на GitHub Pages

Игра выполняется в браузере: отдельный игровой сервер не требуется. Сборка для Pages отделена от обычной локальной сборки Vinext.

```text
npm ci
npm run build:pages
```

Готовый сайт находится в **out**: `index.html`, `favicon.svg`, `.nojekyll`, каталог `assets` с JavaScript, стилями, Web Worker и физикой WebAssembly. Публиковать нужно содержимое out целиком, с сохранением структуры.

По умолчанию ресурсы рассчитаны на адрес вида `https://ИМЯ.github.io/street-racer/` и репозиторий street-racer. Для другого имени репозитория укажите путь перед сборкой. Пример для PowerShell:

```powershell
$env:PAGES_BASE_PATH = '/my-racing-game/'
npm run build:pages
Remove-Item Env:PAGES_BASE_PATH
```

Для сайта в корне домена используйте `PAGES_BASE_PATH=/`.

В GitHub Pages можно публиковать готовые файлы из выбранной ветки либо собирать их в GitHub Actions и передавать `out` в `actions/upload-pages-artifact`, затем `actions/deploy-pages`. Настройка описана в [официальной инструкции GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages). В этой задаче сайт не публиковался, репозиторий не создавался, коммиты и отправка не выполнялись.

В проекте настроен файл `.github/workflows/deploy-pages.yml`: после отправки изменений в ветку `main` GitHub сам установит зависимости, проверит код и тесты, соберёт `out` и опубликует сайт. В настройках репозитория нужно один раз выбрать **Settings → Pages → Source → GitHub Actions**.

Для проверки точно такой статической сборки на компьютере:

```text
npm run preview:pages -- --host 127.0.0.1 --port 3001
```

Откройте `http://localhost:3001/street-racer/`.

Новый район всё равно требует доступа к OSM/Overpass и высотам. Кэш и рекорды хранятся отдельно на каждом устройстве и для каждого адреса сайта: данные с localhost автоматически не перенесутся на GitHub Pages или телефон.
